# 模块一：视频流与分析任务管理接口文档

## 1.1 创建/启动视频流分析任务

| 属性 | 说明 |
| --- | --- |
| **接口描述** | 提交摄像头视频流地址，分配 GPU 算力并启动跌倒风险分析任务，返回 WebSocket 告警通道地址。 |
| **请求路径** | `/api/v1/fall-risk/tasks` |
| **请求方式** | `POST` |

### 请求参数 (Body)

| 参数名 | 必填 | 类型 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `cameraId` | 是 | String | 摄像头的唯一标识符 | `cam_ward_A1_001` |
| `streamUrl` | 是 | String | 实时流地址 (RTSP/RTMP/HLS) | `rtsp://10.0.0.15:554/live/stream` |
| `analyzeMode` | 是 | Integer | 算力分配模式。<br>

<br>`1`: 实时高帧率 (延迟 < 0.5s，高算力)<br>

<br>`2`: 抽帧低功耗 (每秒2帧，低算力) | `1` |
| `sensitivity` | 否 | String | 模型灵敏度，默认 `medium`。<br>

<br>`low`: 仅严重跌倒<br>

<br>`medium`: 标准报警<br>

<br>`high`: 疑似不稳即报警 | `high` |

### 响应数据 (Success 200)

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "taskId": "task_fw29dj391x",
    "status": "connecting", 
    "wsUrl": "wss://ai.domain.com/ws/fall-risk/task_fw29dj391x"
  }
}

```

### 业务异常说明 (Exceptions)

| 错误码 | 错误信息 | 触发场景 | 前端处理建议 |
| --- | --- | --- | --- |
| `40010` | Invalid Stream URL | 视频流地址格式错误或协议不支持。 | 提示“请输入有效的 RTSP/RTMP/HLS 流地址”。 |
| `40012` | Camera Already Analyzing | 该摄像头当前已有正在运行的分析任务。 | 提示“该设备已在分析中，请勿重复创建”。 |
| `50010` | GPU Resource Exhausted | 服务器当前 GPU 显存耗尽。 | 提示“当前系统算力已满，请停止其他任务或稍后再试”。 |

*注：坐标点推荐使用归一化数值 (0.00 ~ 1.00)，即 `坐标值 / 画面宽或高`。这样即使视频流分辨率发生切换，ROI 依然准确生效。*

# 模块四：系统与模型状态接口文档

## 4.1 获取系统算力与资源状态

| 属性 | 说明 |
| --- | --- |
| **接口描述** | 实时获取底层 AI 分析服务器的硬件资源占用情况，包括 GPU 显存使用率和当前并发解析的视频流路数。前端据此判断是否允许用户新建分析任务。 |
| **请求路径** | `/api/v1/system/status` |
| **请求方式** | `GET` |

### 请求参数

*(GET 请求，无路径和请求体参数)*

### 响应数据 (Success 200)

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "systemStatus": "healthy",
    "activeStreams": 24,
    "maxStreamsCapacity": 30,
    "hardware": {
      "gpuModel": "NVIDIA RTX 4090",
      "gpuUsageRate": "82.5%",
      "gpuMemoryUsed": "19800MB",
      "gpuMemoryTotal": "24576MB",
      "cpuUsageRate": "45.2%",
      "ramUsageRate": "60.1%"
    },
    "uptimeSeconds": 1209600
  }
}

```

*字段说明：`systemStatus` 为系统整体健康度枚举值，包含 `healthy` (正常可分配), `warning` (算力接近极限), `critical` (满载或异常)。*

### 业务异常说明 (Exceptions)

| 错误码 | 错误信息 | 触发场景 | 前端处理建议 |
| --- | --- | --- | --- |
| `50020` | Stats Collection Failed | 后端无法读取显卡驱动或系统监控进程超时。 | 在系统状态看板显示“-”，并提示“获取硬件状态失败”。 |

## 4.2 获取当前加载的 AI 模型信息

| 属性 | 说明 |
| --- | --- |
| **接口描述** | 获取当前系统在显存中实际加载的跌倒检测模型版本及推理引擎信息。常用于系统诊断页面和给技术支持人员提单时的附加信息。 |
| **请求路径** | `/api/v1/model/version` |
| **请求方式** | `GET` |

### 请求参数

*(GET 请求，无路径和请求体参数)*

### 响应数据 (Success 200)

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "modelName": "FallDetect-Pose-Net",
    "version": "v2.3.1-trt",
    "inferenceEngine": "TensorRT 8.6",
    "releaseDate": "2026-05-20T00:00:00Z",
    "supportedInputResolutions": ["640x640", "1280x720", "1920x1080"],
    "features": [
      "fall_detection",
      "stumble_warning",
      "bed_exit_warning"
    ],
    "isLoaded": true
  }
}

```

### 业务异常说明 (Exceptions)

| 错误码 | 错误信息 | 触发场景 | 前端处理建议 |
| --- | --- | --- | --- |
| `50021` | Model Not Loaded | 推理服务已启动，但权重文件损坏或加载失败。 | 拦截所有新建分析任务的操作，并在全局顶部展示严重警告：“AI 模型未就绪，请联系管理员”。 |
