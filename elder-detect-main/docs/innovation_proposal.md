# 创新点提案：方向先验 + 测量误差感知的个人基线序贯偏离检验（DS-PCD）

## 0. 先说清楚能验证什么、不能验证什么

| 环节 | 现有数据能否验证 | 原因 |
|---|---|---|
| 7天/30天跌倒概率（Landmark Cox） | **不能** | 仓库和 `_datasets` 只有 UR-FALL：70 段 1.5–9.7 秒的片段，没有受试者 ID、多日记录或跌倒随访。在这类数据上声称 7/30 天 AUROC 提升，经不起推敲。 |
| 视频 → 日级步态特征 → **个人步态变化检出** | **能** | 不需要跌倒标签。用现有摄像头 + 姿态流程就能采集（重复测量 + 可控步态扰动），检出率、延迟和误报率都能直接量化。 |

所以创新点放在**可量化的上游环节**：在误报率一致的前提下，比较谁能更早、更可靠地检出真实步态退化。文献已经确认步态变慢和步态变异性增大是跌倒的前兆（Hausdorff 2001；Verghese 2009），这一环检出得越好，后面接 Cox 模型时的信号就越强。

## 1. 现有方法的可量化缺陷（已用项目代码实测）

[deviation.py](file:///F:/jiebang_team/anti-fall/elder-detect-main/longitudinal/deviation.py#L18-L41) 的做法：先对 11 个特征分别算稳健 z，再取截断 RMS，规则是“RMS ≥ 3 且连续 3 天”。

1. **RMS 稀释**：RMS ≥ 3 等于 11 维平均 |z| ≥ 3，也就是 Σz² ≥ 99。如果只有 2–3 个特征退化 1.5σ，RMS 只有约 0.9，永远到不了阈值。
2. **方向无关**：步速升高（变好）和步速下降（变差）被同等看待，噪声自由度白白翻倍。
3. **测量误差被当成个人波动**：单目短视频里，步数 20 和 150 的会话可靠性差很多，但现在一律同等对待；`step_time_cv` 这类变异性特征在步数少时尤其噪。
4. **只看单日、没有累积**：缓慢退化每天都不显著，但连续多天的累积证据被浪费了。
5. **误报率没有校准**：阈值 3 是经验值，没有对应的误报率。

## 2. 方法（DS-PCD）

1. **测量误差感知的标准化**：每个会话在步级做 bootstrap，得到每个特征的测量标准误 sₜ。14 天基线用 DerSimonian–Laird 随机效应模型估计个人均值 μ 和真实日间波动 τ²。新观测的标准化为：

$$z_{t,k}=\frac{x_{t,k}-\hat\mu_k}{\sqrt{\hat\tau_k^2+s_{t,k}^2+\mathrm{Var}(\hat\mu_k)}}$$

2. **方向先验的单侧 χ̄² 统计量**：退化方向按文献预先固定（步速↓、步频↓、步时↑、步时 CV↑、不对称↑、晃动↑、eMOS↓……）。$T_t=\sum_k \max(0, d_k z_{t,k})^2$，没有方向先验的特征按双侧处理。
3. **个人化零分布校准**：用基线残差估计收缩相关矩阵，蒙特卡洛模拟得到 Tₜ 的零分布，再转成正态分数 qₜ。这一步同时处理了 cadence 和 step_time 近似倒数关系造成的重复计数。
4. **CUSUM 序贯累积**：$C_t=\max(0, C_{t-1}+q_t-k)$。阈值 h 按目标误报率标定（例如每 30 天至少一次误报的概率 ≤ 10%）。

有了随访标签之后，Cₜ 和 Tₜ 可以直接替换 `distance/trend_7d/persistent_deviation_days`，作为 Landmark Cox 的协变量。

## 3. Stage 0 结果：用已知真值的仿真做方法性质检查

脚本：[sim_mea_pcd.py](../scripts/sim_mea_pcd.py)，完整输出：[sim_out.txt](../scripts/sim_out.txt)

- 设置：每组 2000 人，14 天基线加 30 天监测，第 8 天开始退化；指标是退化开始后 21 天内的检出率。
- 公平性：A1–A4 都标定到**相同误报率**（每 30 天至少一次误报的概率 ≤ 10%）。
- 一致性：已核对过，向量化实现的现有方法与项目里的 `compute_deviation` 输出完全一致。

**会话质量不均（20–150 步），退化幅度 1.5τ，突变：**

| 方法 | S1 变异性（稀疏） | S2 变慢 | S3 平衡 | S4 方向先验外 |
|---|---|---|---|---|
| A0 现有默认规则（RMS≥3×3天） | 0.0% | 0.0% | 0.0% | 0.0% |
| A1 现有方法，误报率对齐 | 11.8% | 23.2% | 19.4% | 12.3% |
| A2 + 测量误差感知 z | 17.3% | 34.1% | 27.6% | 15.9% |
| A3 + 方向 χ̄² | 33.7% | 58.0% | 59.3% | 13.0% |
| **A4 DS-PCD 全量** | **47.6%** | **73.2%** | **79.3%** | **17.4%** |

在 14 天内缓慢退化到 1τ 的情形下，A1 只有 8–11%（基本等于误报率），A4 为 21–36%。

**结果中对本方法不利或需要如实说明的部分：**

- 现有默认规则的零假设误报率是 0，检出率也是 0：它实际上不会报警。
- 去掉会话质量差异（固定 60 步）后，A2 的增益几乎不变。说明在这个仿真里，A2 的提升主要来自均值估计比中位数/MAD 更有效，**而不是**“按会话精度加权”本身。精度加权的价值要靠真实数据确认，不能预先声称。
- 主要增益来自**方向先验**和 **CUSUM**。代价是 S4（退化方向不在先验内）时，A3 反而低于 A1，A4 只和 A1 持平或略好。所以需要保留双侧综合偏离作为“异常提示”通道。
- 噪声比例、相关结构等仿真参数都是假设值。仿真只证明统计性质，**不能当作实证结论**。

## 4. Stage 1：用现有系统采集的真实数据验证（需要先预注册）

- **对象与设备**：5–8 名志愿者，固定摄像机机位，沿用现有 MediaPipe 和 `summarize_pose_sequence` 流程。
- **基线阶段**：每人 14 个会话，每个会话 3–5 趟、每趟约 10 米步行（每天 1–2 次，共 1–2 周）。
- **扰动阶段**：随机顺序、盲态分析，每种条件 3–5 个会话，混入无扰动会话作为对照。
  - 双任务行走（连续减 7）：文献证实能提高步态变异性、降低步速。
  - 单侧踝部负重 2–3 kg：主要改变不对称性。
  - 护膝限制屈膝：改变步时和姿态。
- **主要终点**：误报率对齐时，扰动会话的检出率（DS-PCD 对比现有方法），用配对 McNemar 检验，按受试者聚类 bootstrap 给出 95% CI。
- **次要终点**：会话级 AUROC；检出延迟；各特征的 ICC(3,1)、SEM、MDC95，对比 bootstrap 精度加权前后；无扰动会话中实际观察到的误报率。
- **消融**：A1 到 A4 逐项加入，回答每个组件分别贡献多少。
- **局限**：健康人的诱发扰动不等于老人的自然退化。这一阶段验证的是“检出步态变化的能力”，不是“预测跌倒的能力”。后者仍然需要真实随访标签，到时再用 Landmark Cox 加独立验证完成。

## 5. 一句话版本

> 在误报率对齐（每 30 天至少一次误报的概率 ≤ 10%）的条件下，把现有的“稳健 z 的 RMS + 固定阈值”换成“测量误差感知标准化 + 方向先验单侧检验 + CUSUM”。在已知真值的仿真中，1.5τ 退化的 21 天检出率从 12–23% 提高到 48–79%。真实效果用现有摄像系统采集的诱发步态扰动数据，按 McNemar 检验和受试者聚类 CI 来检验。
