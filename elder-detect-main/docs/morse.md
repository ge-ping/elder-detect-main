# Morse跌倒评估量表（中文版）完整说明
## 一、量表简介
Morse跌倒评估量表（Morse Fall Scale，MFS）由美国宾夕法尼亚大学Janice Morse教授于1989年编制，最初用于医院急性病房成人跌倒风险预判，后续拓展至康复科、长期照护机构。
2009年周君桂团队完成中文版翻译、本土化与信效度检验（三甲住院老年人群样本）：
1. 内部一致性Cronbach’s α校正后0.187，各条目相互独立；
2. 测评者间相关系数＞0.7（P＜0.01），评分一致性优秀；
3. 内容效度、区分效度达标，适用于国内住院患者跌倒筛查。

## 二、量表内容及填写说明
量表共6项评估维度，逐项计分累加，总分区间**0～125分**，分值越高跌倒风险越高；评估以患者实时状态为准，客观打分。

### 表1 Morse跌倒评估量表计分细则
|评估项目|评分细则|对应分值|
| ---- | ---- | ---- |
|1. 跌倒史|近3个月/既往有跌倒史<br>无跌倒史|25分<br>0分|
|2. 存在多项疾病诊断|≥2种合并慢性病<br>仅单一疾病|15分<br>0分|
|3. 行走辅助工具|依靠家具借力行走<br>使用拐杖/助行器<br>卧床/无需辅助、护士全程搀扶|30分<br>15分<br>0分|
|4. 静脉输液/肝素锁|当前正在输液/留置管路<br>无输液置管|20分<br>0分|
|5. 步态情况|肢体残疾/活动障碍<br>双下肢乏力<br>步态正常、长期卧床无法活动|20分<br>10分<br>0分|
|6. 精神认知状态|高估行动能力、健忘、自控差<br>能正确判断自身活动限制|15分<br>0分|

## 三、量表评分标准与干预方案
总分划分三级跌倒风险，配套标准化护理防控措施。

### 表2 MFS风险分级与干预策略
|风险等级|总分区间|标准化防控措施|
| ---- | ---- | ---- |
|低风险|＜25分|1.入院宣教，指导穿戴防滑鞋；<br>2.病房、走廊清除障碍物，保证照明；<br>3.卫生间安装扶手、紧急呼叫铃；<br>4.按需提供助行器具；<br>5.常用物品放置随手可取位置；<br>6.规范病床、平车、轮椅安全使用。|
|中风险|25～45分|1.床头放置防跌倒警示标识；<br>2.呼叫器放置患者手边，建议家属陪同；<br>3.教会患者正确使用辅助行走工具；<br>4.严格要求穿着防滑合适鞋袜；<br>5.观察降压、镇静类药物不良反应；<br>6.向患者及家属开展跌倒预防宣教。|
|高风险|＞45分|1.告知家属必须专人24小时陪护；<br>2.通知管床医生开展针对性干预；<br>3.增加巡视频次，全程辅助活动；<br>4.独处、意识模糊时拉起床栏防护；<br>5.必要时采取适度保护性约束；<br>6.纳入交接班重点观察内容。|

## 四、量表使用注意事项
### （一）评估时机
1. **入院即刻**：首次基础跌倒风险筛查；
2. **转科/换病房**：环境变化后重新评估；
3. **病情波动**：术后、新发疾病、调整用药后即时复测。

### （二）评估频率
1. 高风险（＞45分）：每日评估1次；
2. 发生跌倒/病情剧变：立即复测；
3. 稳定长期住院患者：每周1～2次评估追踪。

### （三）评估核心要点
1. 问询核实：与患者、家属沟通确认跌倒史、慢性病、服药情况；
2. 现场观察：直观步态、行动、意识状态，避免主观臆断；
3. 综合判断：不可单一条目下定论，以总分综合判定风险等级。
