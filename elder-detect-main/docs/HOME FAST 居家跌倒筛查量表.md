# HOME FAST 居家跌倒筛查量表（完整版·含计分、评判标准、风险分级）
## 基础信息
|项目|内容|
| ---- | ---- |
|量表全称|Home Falls and Accidents Screening Tool（居家跌倒意外筛查工具）|
|条目总数|25题，满分25分|
|计分规则|每题：选「否」记1分；选「是/不适用(N/A)」记0分；总分=全部“否”选项累加值|
|核心逻辑|总分越高，居家跌倒环境隐患越多、跌倒环境风险越高|
|风险分级标准|0～4分：低风险；5～7分：中风险；≥8分：高风险|
