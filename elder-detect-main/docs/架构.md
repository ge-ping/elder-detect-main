# 系统架构（当前实现）

> 老年人跌倒**检测与预判**系统 —— 基于 MediaPipe Pose + 2 层 LSTM 时序建模
> 三分类：`Normal`（正常）/ `Unstable`（失衡前兆）/ `Fall`（已跌倒）
> 对齐论文5（Lau et al., 2022）Attention-GRU 三分类思路，但**模型实现为 2 层 LSTM**。

## 2. 已实现模块详情

### `pose/` —— 姿态提取（对外 API 见 `docs/api/pose.md`）

```
pose/
├── __init__.py         # 公开导出: PoseExtractor, PoseResult, BodyPart, load_pose_config ...
├── keypoint.py         # Keypoint, PoseResult, BodyPart(33枚举)
│                        #   CORE_JOINTS_13, MINIMAL_JOINTS_3, ALL_JOINTS_33
│                        #   PoseResult: .array(N,4), .get(), .get_world(),
│                        #     .clone_with_normalized_coords(), .clone_with_3d_normalized()
├── extractor.py        # PoseExtractor, PoseExtractorConfig
│                        #   方法: detect_frame, process_video, process_image,
│                        #         process_batch, process_webcam, close
└── config_loader.py    # load_pose_config(YAML), create_config_from_dict
```

**输出 `PoseResult`**：
- `landmarks`：N 个关键点，x,y ∈ [0,1] 归一化，z = 相对深度
- `world_landmarks`：N 个关键点，3D 世界坐标，单位：米，原点：髋中心
- `timestamp_ms`, `frame_width`, `frame_height`

### `features/` —— 单帧 29 维特征（当前主干）

```
features/
├── __init__.py          # 公开导出 FrameFeatureBuilder
├── feature_builder.py   # ★ FrameFeatureBuilder: 单帧 → (29,) 当前主干
├── base.py              # FeatureExtractor (ABC, 旧设计遗留)
├── types.py             # FeatureResult (旧 5 维设计遗留, 未接入主干)
├── torso.py             # TorsoAngleExtractor  — 躯干 3D 倾角
├── gait.py              # GaitSpeedExtractor   — 逐帧步行速度
├── skeleton.py          # SkeletonFeatureExtractor — 人体宽高比 Rf
├── joint_angle.py       # 关节角度 (+7 维, 实验 V4 用, 默认关闭)
└── pipeline.py          # FeaturePipeline 串联器 (旧设计遗留, 未接入主干)
```

**当前主干 `FrameFeatureBuilder.build(result, gait_speed)` → (29,) float32**

| 索引 | 字段 | 来源 | 坐标系 |
|------|------|------|--------|
| 0 | `gait_speed` | `GaitSpeedExtractor.compute_per_frame()` | world_landmarks (米) |
| 1 | `trunk_angle` | `TorsoAngleExtractor.extract_frame()` 三平面 arctan2 | world_landmarks → [-1,1] |
| 2 | `aspect_ratio` | `SkeletonFeatureExtractor.extract_frame()` | landmarks [0,1] |
| 3–28 | `skeleton_26` | `PoseResult.landmarks[CORE_JOINTS_13]` | landmarks [0,1] |

13 核心关节固定顺序：NOSE → LEFT_SHOULDER → RIGHT_SHOULDER → LEFT_ELBOW →
RIGHT_ELBOW → LEFT_WRIST → RIGHT_WRIST → LEFT_HIP → RIGHT_HIP →
LEFT_KNEE → RIGHT_KNEE → LEFT_ANKLE → RIGHT_ANKLE

> ⚠️ **两套 `FrameFeatureBuilder` 并存**：
> - `features/feature_builder.py`（当前主干，29 维，接口 `build(result, gait_speed)`）
> - `sequence/feature_vector.py`（旧版，config 驱动，接口 `build(result, scalars_dict)`）
> 主干与 `build_from_cache.py` / `demo.py` 一律用 `features/` 这一套。

### `sequence/` —— 滑动窗口

```
sequence/
├── __init__.py          # 导出 WindowConfig, SlidingWindowBuilder
├── config.py            # WindowConfig(window_size, stride, joint_set, ...)
├── window.py            # ★ SlidingWindowBuilder.build_from_array() → (N,W,K)
├── velocity.py          # add_velocity / add_acceleration (实验 V2/V3 用)
└── feature_vector.py    # 旧版 FrameFeatureBuilder (见上方警告)
```

**`SlidingWindowBuilder.build_from_array(features, labels)`**：
- 输入：`(T, K)` 特征数组 + `(T,)` 逐帧标签
- 输出：`(N, window_size, K)` + `(N,)` 标签
- **窗口标签 = 窗口最后一帧的标签**（`labels[start + window_size - 1]`）
- 不足 `window_size` 帧的视频直接丢弃（pad_mode 实际为 "discard"）

### `model/lstm/` —— 模型与实验

```
model/lstm/
├── model.py             # ★ FallLSTM: 2 层 LSTM(64, 两层均为 64) + Dropout + FC(3)
└── evolution.md         # 实验记录 (V1~V5, 权重消融, Pre-VFall)
```

**`FallLSTM` 关键事实**（与旧架构文档不同）：
- 输入 `(N, W, 29)`，输出 `(N, 3)` logits
- 取**最后一帧** hidden state：`out = lstm(x); out[:, -1, :]`
- **无 Attention、无 GRU**，就是朴素 2 层 LSTM

### 环境风险与融合（Phase-2，2026-07-13 新增）

环境风险改用 **HOME FAST 居家跌倒筛查量表（25 题）**（`model/env/env_risk_model.py · HomeFastModel`），完全取代旧的 `RuleEnvRisk` 三查表（room/light/floor）。关键事实：

- **单一环境分 E = T / N_obs**（T=25 题隐患总分，N_obs=实际观察题数，N/A 题整体剔除不进分母），∈[0,1]；风险分级由绝对总分 T 决定：0~4 低 / 5~7 中 / ≥8 高。
- **R0/R1 共用一套规则表**：R1 = VLM 看画面打 HOME FAST 细标签 → `from_labels()` 换算 25 题 0/1；R0 = 问卷直传答。VLM 对看不清的字段输出 `null`（不瞎猜）→ 跳过当 N/A。
- **覆盖度守卫**：`N_obs/25 < HOME_FAST_COVERAGE_FLOOR(0.6)` → `need_review=True`（E 仅反映已观察部分、不可全信）。
- **融合（`fuse_risk.py`）**：E 只调报警/预警阈值（θ），**不进 `risk_short` 分数**；硬下限 `THR_ALARM_FLOOR=0.45`；`CTX_W_E=0.60 / CTX_W_P=0.40`。
- **VLM 链路**：`env_extract_frames.py`（抽帧）→ `env_label_vlm.py`（火山方舟 ark + Doubao-Seed-1.6-vision，超时 60s + 逐帧进度）→ `env_labels_to_risk.py`（转 risk / 写 sidecar）；`env_perceive.py` 编排 R1 优先 / R0 回退。

> 设计详述与算例见 `docs/跌倒风险预测_汇报.md` §3。环境模型为纯规则、零训练零推理成本，`model/env/env_risk_model.py` 即单一真相源。

|----------|---|---|---|------|------|

## 4. 标签与风险定义

### 三分类标签

| 标签 | 类别 | 英文 | 定义 |
|------|------|------|------|
| `0` | 正常 | Non-fall | 站立、行走、坐下、弯腰等日常活动 |
| `1` | 失衡 | Pre-impact fall | 撞击地面前的失衡阶段（身体倾斜、步态异常、即将摔倒） |
| `2` | 跌倒 | Fall | 已倒地 / 撞击地面（躺卧、无法自主站起） |

### 实时风险公式（以 `demo/demo.py` 为准）

```
Risk = 0.1·P(Normal) + 0.6·P(Unstable) + 0.9·P(Fall)
SAFE     : Risk < 0.3
WARNING  : 0.3 ≤ Risk < 0.6
DANGER  : Risk ≥ 0.6
```

> ⚠️ 旧文档（`temp/current_direction.md` 旧版、`model/lstm/evolution.md` 旧版）曾写为
> `P(U)·0.6 + P(F)·1.0` 或 `P(F)·1.0`，均已修正为上方公式（P(F) 系数 0.9，
> 且包含 P(N) 项）。

## 5. 构建脚本三条路径说明

| 路径 | 脚本 | 输入布局 | 状态 |
|------|------|----------|------|
| **主线（推荐）** | `build_cache.py` → `build_from_cache.py` | 5 个公开研究数据集原始目录 | ✅ 当前使用 |
| 遗留逐数据集 | `build_le2i.py` / `build_urfall.py` / `build_caucafall.py` / `build_upfall.py` | 同上，但每个数据集一个脚本直跑 MediaPipe | 历史遗留，已被主线取代 |
| 通用单文件夹 | `build_dataset.py` + `datasets/dataset_builder.py` | `normal/` + `fall/` 两文件夹 | 通用工具，未用于本项目的 5 个研究数据集 |

**主线命令**：
```bash
# 阶段 1（一次性，慢）: 5 数据集 → pose_cache/*.npz
python scripts/build_cache.py            # 全部
python scripts/build_cache.py Le2i     # 单个

# 阶段 2（可反复，快）: 缓存 → 特征 → 窗口
python scripts/build_from_cache.py -v v1                 # 默认窗口 35
python scripts/build_from_cache.py -v v1 -w 25          # 最佳实验窗口 25
python scripts/build_from_cache.py -v v5_w25 --output datasets/experiment/v5_w25

# 训练
python scripts/train_lstm.py -v v5_w25

# 实时演示
python demo/demo.py --model model/lstm/v5_w25/run_01/best_model.pt
```
